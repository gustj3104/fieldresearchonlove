# 표지 시안(사용자 제공) 분석 메모

최신본: `source/cover-design_W135xH195-template_v2-100.pdf` (뒷면 "200가지" → "100가지" 수정, 그 외 v1과 동일) / 이전본: `source/cover-design_W135xH195-template_from-user.pdf` (1쪽, 7221×5013pt = 태산인디고 W135XH195 템플릿 336×233mm의 약 7.58배 확대 캔버스)

## 구조 (템플릿 mm 기준)
- 앞/뒷표지 패널 각 141×201mm, 책등 22mm, 바깥 16mm 편집영역 → 뒷표지 16–157, 책등 157–179, 앞표지 179–320
- 요소 중심: 뒷표지 글 x≈87 / 앞표지 제목 x≈250.5 / 책등 글 x≈169.8 → 템플릿 패널 중심(86.5 / 249.5 / 168)과 일치 = **135×195 책 기준으로 제작됨**
- 내지는 A5(148×210) → 보드가 책보다 작아지므로 **규격 불일치, 결정 필요**

## 기술 상태
- 색: ICC 기반 RGB (검정 배경 0,0,0 + 흰 글자). 인쇄용 CMYK 변환 시 배경을 K100(또는 리치블랙)로 지정 필요
- 글꼴: Type3(글자가 벡터 글리프) → 글꼴 임베드 문제 없음, 텍스트 추출은 불가
- 이미지 3개: 일러스트 2개(약 1000ppi 이상, 충분), **전체 배경 검정 래스터 1개(1810×1257px, 약 137ppi)** → 벡터 검정 사각형으로 교체 권장

## 내용 정리 (사용자 확정)
- 한글 제목 `사랑행동`(붙여 씀), 영문 제목 `Acts of Love` → **내지(속표지·판권)를 표지에 맞춰 수정 완료**
- 사랑 행동 개수는 **100개** → 내지 100개, **표지 v2에서 "100가지"로 수정 완료**
- 표지 맺음 문장 "여러분의 쉬운 사랑을 기원합니다." ↔ 서문 "…위하여 !" 는 서로 다른 문구로 유지(확인됨)
