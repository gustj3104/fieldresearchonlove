# 인쇄소 제출 전 확인 항목 — 《사랑 행동》 내지 (인쇄용 시안)

> 현재 파일은 **인쇄용 시안**입니다. 문구·사용법 원고, 서문·후기·Special thanks, 사랑 행동 100개, 일러스트 5종은 반영됐지만 판권 정보가 없는 상태이므로 그대로 발주하지 마세요.

## A. 태산인디고(인쇄소)에 문의해 확정할 것
1. 하드커버 양장(사철) **내지 도련 값** (기본 3mm로 제작 → `python3 build.py --bleed N` 으로 변경)
2. **재단선·도련 포함 여부** (도련 O/재단선 X 가 기본 파일, 재단선 포함본·무도련본도 같이 생성됨)
3. **PDF 규격**: PDF/X-4 요구 여부, 투명도·레이어 허용 여부, 색상 모드(내지 흑백 1도 → Gray 또는 K100 CMYK)
4. **사철 접지 단위**: 현재 212쪽 = 4의 배수(8p 접지 단위에는 4쪽 부족 → 216쪽으로 빈 면 추가 필요 여부 확인). 16p/32p 단위 접지면 224쪽(또는 240쪽)으로 8쪽 이상 추가해야 하므로 확인 필요
5. **안쪽 여백(제본쪽) 보정**: 현재 안쪽 18mm / 바깥 16mm. 양장 사철은 펼침 시 안쪽이 감기는 정도가 인쇄소마다 다름
6. **용지**: 미색 모조 100~120g 확정 후 **책등 두께** 산출 (표지 전개도에 필요)
7. **면지·표지 별도 파일** 여부. 이 PDF는 내지 216쪽만 포함하며 면지·표지·책등·싸개 여유·홈 위치는 임의로 확정하지 않았음 (인쇄소 사양 필요)
8. **표지 시안(`cover/source/…W135xH195-template…pdf`)은 W135×H195 템플릿 기준으로 제작됨** → 인쇄소 답변 후 A5 재배치 또는 책 크기 변경 결정 (분석: `cover/design-notes.md`)
9. 첨부해 주신 `W135XH195SS22.pdf`는 135×195mm 표지 계열 템플릿으로 보입니다. A5(148×210) 내지와 규격이 다르므로 **A5 책자용 템플릿이 따로 있는지** 확인해 주세요
